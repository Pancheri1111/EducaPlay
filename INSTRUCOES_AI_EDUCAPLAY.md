# RELATORIO DE TRANSICAO - PROJETO EDUCAPLAY

ESTE ARQUIVO EH PARA A PROXIMA IA QUE ASSUMIR O PROJETO APOS A FORMATACAO DO PC.

## CONTEXTO DO PROJETO
- Nome: EducaPlay (App educativo infantil).
- Tecnologias: Flutter (Dart) + Java (Nativo Android).
- Gerenciamento de Estado: Riverpod (ConsumerWidget/ConsumerStatefulWidget).
- Persistencia: Hive (Box 'settings' e 'scores').

## DIRETRIZES DE ESTILO (MUITO IMPORTANTE)
- Estilo: O projeto deve parecer feito por um ESTUDANTE.
- Sem Emojis: Nao use emojis em nomes, comentarios ou documentacao para evitar suspeitas do professor.
- Estrutura Simples: Todos os arquivos estao em 'lib/pages/' para facilitar a manutencao pela equipe de estudantes.
